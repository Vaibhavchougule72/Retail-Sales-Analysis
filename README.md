## 📌 **Project Overview**
This project demonstrates an **end-to-end data analytics workflow** — from cleaning raw sales data in Excel to building an interactive Power BI dashboard.

It focuses on **data quality, accuracy, and storytelling through visuals**.

---

## 🎯 **Aim of the Project**
To clean, validate, and analyze 2 years (2023–2024) of retail sales data and present meaningful insights through a Power BI dashboard.

---

## 🧩 **About the Dataset**
- 1500 rows of retail transactions  
- Columns: Order ID, Customer ID, Product ID, Sales, Quantity, Discount, Profit, Order Date, Ship Date, Region, State, etc.  
- Dataset includes missing values, outliers, and inconsistent entries — intentionally kept for real-world data cleaning practice.

## 🧹 **Data Cleaning Process**
**14-Step Process (Excel):**
1. Backup original file  
2. Inspect data shape and missing values  
3. Standardize column names  
4. Trim and clean text columns  
5. Parse dates & convert numerics  
6. Flag and impute missing values  
7. Detect and mark duplicates  
8. Standardize categories  
9. Validate business logic  
10. Handle missing values  
11. Detect and flag outliers  
12. Create derived columns  
13. Sanity check totals  
14. Save and document results  

Detailed formulas are available in:
[`Scripts/data_cleaning_steps.txt`](./Scripts/data_cleaning_steps.txt)

## 💡 **Key Insights**
- Most profitable segment: *Corporate*  
- Highest sales in *West Region*  
- Outliers in profit were due to extreme discounts  
- Seasonal sales peaks observed during Q4 (Festive period)
